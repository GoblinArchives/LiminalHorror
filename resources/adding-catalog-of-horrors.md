# Catalog of Horrors (adding Monsters to directory on the website)
If you would like to submit a monster to be included on the website, please send a markdown or text file to goblinarchivepdx@gmail.com (or on the discord).
- Note the Front Matter (starting with `---`) at the beginning, and the empty line at the end.
- Note the space between the Monster Name, the stats, and the special entries.
- Include every ability score, _even if they are only 10_.
- For an example, see [here]() and the raw text [here]()
- Monster submissions to the website must utilize the following format.


```
---
layout: default
title:
parent: Catalog of Horrors
grand_parent: Resources
---

# Name
Description

STR: X DEX: X CTRL: X

HP: X Armor: X

Weapon Attack (d6) or Special Attack(d6 Stress)
- Special Ability: An ability that causes corruption, hits multiple targets, or changes the environment in some manner.
- Special Ability: An ability that either enhances its allies or creates new horrors

```
