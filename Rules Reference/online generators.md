# Digital Tools
As Liminal Horror continues to grow, there is a plethora of digital tools and aids that come up for it. Many build upon already available resources, while some present completely orignal content.

The best way to keep up to date on the available digital tools (especially third party tools) is to search the [Liminal Horror Library](https://liminalhorrorlibrary.com/) for [perchance](https://liminalhorrorlibrary.com/tag/perchance/) or for [tools](https://liminalhorrorlibrary.com/category/tools/).

## Searchable Rules Reference
This site acts as a digital tool in that it is a fully searchable rules reference that can be launched from a phone. It is not only the foundation for the game, but acts as the progenitor of the digital tools for Liminal Horror.
